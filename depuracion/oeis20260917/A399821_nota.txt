Number of new Collatz merging classes at level n with exactly 12 mixed-parity steps.

DATA
0, 0, 0, 1, 5, 18, 52, 134, 315, 681, 1393, 2698, 4947, 8712, 14818, 24465, 39278, 61513, 94110, 140829

OFFSET
10,5

COMMENTS
Let T be the Collatz map (A014682): T(x) = x/2 if x is even, T(x) = (3*x+1)/2 if x is odd. A new merging class at level n is a residue class modulo 2^n for which the pair (r,r+1) merges at step n with equal odd count and is not inherited from a merging class at level n-1.

This sequence counts the new classes whose two trajectories have opposite parity at exactly 12 of the n steps. The first term is for n = 10.

This is the third nontrivial high stratum in the same family as A399819 and A399820. Exact computation in the range shown finds no quasipolynomial formula of degree <= 8 and period <= 8 starting by n <= 16.

Checked against OEIS on Sep 12 2026 with the displayed terms: no results.

LINKS
Omar Said, <a href="https://github.com/theswordofthemorning/zootheorem">Statements, proofs, sequence data and verification scripts</a>

EXAMPLE
a(13) = 1: the first new merging class with exactly twelve mixed-parity steps appears at level 13.

PROG
(Python)

def step(x):

    return (3*x + 1)//2 if x & 1 else x//2

def ok(r, n):

    x, y, sx, sy, m = r, r+1, 0, 0, 0

    for t in range(1, n+1):

        m += ((x ^ y) & 1)

        sx += x & 1; sy += y & 1

        x, y = step(x), step(y)

        if x == y:

            return t == n and sx == sy and m == 12

    return False

def a(n):

    return sum(ok(r, n) for r in range(2**n - 1))

COMMENTS
Let T be the Collatz map (A014682): T(x) = x/2 if x is for even, T( x) =  and (3*x+1)/2 if x is for odd x. A new merging class at level n is a residue class modulo 2^n Iterate T simultaneously from r and r+1, for which the pair (r,each integer r+1) merges at step n  with equal odd count and is not inherited from a merging class at level 0 <= r < 2^n-1.

This sequence counts the new classes whose two trajectories have opposite parity at exactly 12 of the n steps. The first nonzero term is for n = 13.

This is the third nontrivial high stratum in the same family as A399819 and A399820.

Count r if the two trajectories first meet after exactly n iterations, have the same number of odd inputs among these n iterations, and have opposite input parities at exactly 12 of them. An iteration with opposite input parities is called a mixed-parity step; steps are numbered 1 through n, including the meeting step.

The first nonzero term is at n = 13. The sequences A399819, A399820 and A399821 count the cases with 8, 10 and 12 mixed-parity steps, respectively.

The equal odd counts ensure that the meeting holds for the entire residue class modulo 2^n: if each path has s odd inputs, replacing r by r + 2^n*m adds 3^s*m to both values at step n. Thus each counted r represents an infinite family of consecutive pairs, not just one numerical coincidence.

These sequences refine A398793 by the number of mixed-parity steps. If e_j(n) denotes the same count with j mixed-parity steps, then sum_j e_j(n) = A398793(n-1) = A398792(n) - 2*A398792(n-1), for n >= 2. Only even j can occur, since equal odd counts require equally many mixed steps of each orientation.

This decomposition records how different parity patterns contribute to the density of merging consecutive pairs, in connection with the question studied by Gao. The quantity e_j(n)/2^n is the density added at level n by that part of the count. Proving lim A398792(n)/2^n = 1 remains an open objective; the three fixed values j = 8, 10, 12 alone do not settle it.

The counts require only finite trajectories and do not assume the Collatz conjecture. For lifted pairs r + 2^n*m, r + 2^n*m + 1 with m >= 1, equal finite total stopping times follow if their common trajectory reaches 1.

REFERENCES
G.-G. Gao, On consecutive numbers of the same height in the Collatz problem, Discrete Mathematics 112 (1993), 261-267.
