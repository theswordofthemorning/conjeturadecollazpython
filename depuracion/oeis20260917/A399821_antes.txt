%N Number of new Collatz merging classes at level n with exactly 12 mixed-parity steps.
%C Let T be the Collatz map (A014682): T(x) = x/2 if x is even, T(x) = (3*x+1)/2 if x is odd. A new merging class at level n is a residue class modulo 2^n for which the pair (r,r+1) merges at step n with equal odd count and is not inherited from a merging class at level n-1.
%C This sequence counts the new classes whose two trajectories have opposite parity at exactly 12 of the n steps. The first nonzero term is for n = 13.
%C This is the third nontrivial high stratum in the same family as A399819 and A399820.
