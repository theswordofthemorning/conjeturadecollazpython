#10 by Sean A. Irvine at Sun Aug 23 19:08:59 EDT 2026
NAME
Number of residues r in [values 0,  <= r < 2^n)  such that the trajectories of r and r+1 under the Collatz map T f (A014682), T(x) = x/2 if x is even and (3x+1)/2 if x is odd, satisfy Tf^(n)(r) = Tf^(n)(r+1) and contain the same number of odd terms among the first n iterates.
COMMENTS
By Terras's theorem, the first n parities of a trajectory depend only on the residue mod 2^n, and Tf^(n)(2^n*m + r) = 3^s*m + Tf^(n)(r) where s is the number of odd steps of r; hence the counted condition holds for entire residue classes: every pair (2^n*m + r, 2^n*m + r + 1) with m >= 1 in a counted class merges, and both members have equal total stopping time whenever the merged trajectory reaches 1 (unconditionally true for all values below 2^71, see Barina).
Computing a(n) requires deciding all 2^n residue classes, so the cost doubles with each further term; the terms listed are at the current computational limit.
FORMULA
a(n+1) >= 2*a(n). See the first comment.
EXAMPLE
a(3) = 1: the residue r = 4 satisfies Tf^(3)(4) = Tf^(3)(5) = 2 with one odd step on each side (4 -> 2 -> 1 -> 2 and 5 -> 8 -> 4 -> 2), so every pair (8m+4, 8m+5) with m >= 1 merges in 3 steps.

NAME
Number of residues r in [0, 2^n) such that the trajectories of r and r+1 under the shortcut Collatz map T (A014682), T(x) = x/2 if x is even,  and (3x+1)/2 if x is odd) , satisfy T^n(r) = T^n(r+1) and contain the same number of odd terms among the first n iterates.
COMMENTS
a(n+1) >= 2*a(n) for all n: with m = 1 in Terras's identity, both r and r + 2^n inherit the property. Hence a(n)/2^n is nondecreasing, and every value is a proved lower bound for the lower density of pairs of consecutive integers with equal Collatz height: a(32)/2^32 = 0.435658..., by exact integer computation over all 2^32 residues (no sampling).
Relation to the 3x+1 problem: a(n)/2^n is a nondecreasing lower bound for the density of pairs of consecutive integers of equal Collatz height, and the classes counted at n = 3 and n = 5 are exactly the families of Garner and of Wu and Huang cited above, so the sequence gives the exact form of families that were previously known one at a time. It is not evidence for or against the Collatz conjecture: the map (3x-1)/2 gives the same values (see the comment above).
Computing a(n) requires deciding all 2^n residue classes, so the cost doubles with each further term; the terms listed are at the current computational limit.

Number of residues r in [0, 2^n) such that the trajectories of r and r+1 under the shortcut Collatz map (x/2 if x is even, (3x+1)/2 if x is odd) satisfy T^n(r) = T^n(r+1) and contain the same number of odd terms among the first n iterates.

COMMENTS
By Terras's theorem, the first n parities of a trajectory depend only on the residue mod 2^n, and T^n(2^n*m + r) = 3^s*m + T^n(r) where s is the number of odd steps of r; hence the counted condition holds for entire residue classes: every pair (2^n*m + r, 2^n*m + r + 1) with m >= 1 in a counted class merges, and both members have equal total stopping time whenever the merged trajectory reaches 1 (unconditionally true for all values below 2^71, see Barina).

Hence a(n)/2^n is nondecreasing, and every value is a proved lower bound for the lower density of pairs of consecutive integers with equal Collatz height: a(32)/2^32 = 0.435658..., by exact integer computation over all 2^32 residues (no sampling).
The class r = 4 mod 8 (n = 3) is Garner's pair (8k+4, 8k+5); the class r = 5 mod 32 (n = 5) is the family (32m+5, 32m+6) of Wu and Huang.
The map (3x-1)/2 yields the identical sequence for all n: negation conjugates the two maps, and the reflection r -> 2^n - 1 - r maps one counted set onto the other (machine-checked proof in Lean 4 at the link).

def a(n):    
c = 0    
for r in range(2**n):        
x, y, sx, sy = r, r+1, 0, 0        
for _ in range(n):            
sx += x & 1; sy += y & 1            
x = (3*x+1)//2 if x & 1 else x//2            
y = (3*y+1)//2 if y & 1 else y//2            
if x == y:                
c += sx == sy                
break    
return c
