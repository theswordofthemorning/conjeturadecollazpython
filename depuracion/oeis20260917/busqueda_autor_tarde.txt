A398792
Number of values 0 <= r < 2^n such that the trajectories of r and r+1 under the Collatz map f (A014682), satisfy f^(n)(r) = f^(n)(r+1) and contain the same number of odd terms among the first n iterates.

1,4
COMMENTS
By Terras's theorem, the first n parities of a trajectory depend only on the residue mod 2^n, and f^(n)(2^n*m + r) = 3^s*m + f^(n)(r) where s is the number of odd steps of r; hence the counted condition holds for entire residue classes: every pair (2^n*m + r, 2^n*m + r + 1) with m >= 1 in a counted class merges, and both members have equal total stopping time whenever the merged trajectory reaches 1 (unconditionally true for all values below 2^71, see Barina).
a(n+1) >= 2*a(n) for all n: with m = 1 in Terras's identity, both r and r + 2^n inherit the property. Hence a(n)/2^n is nondecreasing, and every value is a lower bound for the lower density of pairs of consecutive integers with equal Collatz height: a(32)/2^32 = 0.435658..., by exact integer computation over all 2^32 residues (no sampling).
The class r = 4 mod 8 (n = 3) is Garner's pair (8k+4, 8k+5); the class r = 5 mod 32 (n = 5) is the family (32m+5, 32m+6) of Wu and Huang.
The map (3x-1)/2 yields the identical sequence for all n: negation conjugates the two maps, and the reflection r -> 2^n - 1 - r maps one counted set onto the other (machine-checked proof in Lean 4 at the link).
Relation to the 3x+1 problem: a(n)/2^n is a nondecreasing lower bound for the density of pairs of consecutive integers of equal Collatz height, and the classes counted at n = 3 and n = 5 are exactly the families of Garner and of Wu and Huang cited above, so the sequence gives the exact form of families that were previously known one at a time. It is not evidence for or against the Collatz conjecture: the map (3x-1)/2 gives the same values (see the comment above).

FORMULA
a(n+1) >= 2*a(n).
EXAMPLE
a(3) = 1: the residue r = 4 satisfies f^(3)(4) = f^(3)(5) = 2 with one odd step on each side (4 -> 2 -> 1 -> 2 and 5 -> 8 -> 4 -> 2), so every pair (8m+4, 8m+5) with m >= 1 merges in 3 steps.

(Python)
def a(n):    
c = 0    
for r in range(2**n):        
x, y, sx, sy = r, r+1, 0, 0        
for _ in range(n):            
sx += x & 1; sy += y & 1            
x = (3*x+1)//2 if x & 1 else x//2            
y = (3*y+1)//2 if y & 1 else y//2            
if x == y:                
c += sx == sy                
break    
return c

A398793
Number of residues r mod 2^(n+1) such that r and r+1 have the same image and the same number of odd terms after n+1 iterations of the Collatz map (A014682) and such that r mod 2^n does not already have this property at level n.

OFFSET
1,4
COMMENTS
Let f^(n) denote the n-th iteration of the Collatz map.
Nonnegative for all n: by Terras's theorem (1976) the first n parities of a trajectory depend only on the residue mod 2^n, and f^(n)(2^n*m + r) = 3^s*m + f^(n)(r), where s is the number of odd terms among the first n iterates of r. Taking m = 1 shows that if r is counted in A398792 at level n, then both r and r + 2^n are counted at level n+1, whence A398792(n+1) >= 2*A398792(n).
The pair (2^j - 2, 2^j - 1) merges for the first time at step j+2 for every even j >= 2, with merge point at the ternary repunit (3^(j-1)-1)/2, so new classes appear at infinitely many levels.
The ratio a(n+1)/a(n) increases toward 2 on the computed range (1.9469 at n = 35); whether its limit is 2 is equivalent to whether the density bound A398792(n)/2^n converges to the full density of consecutive pairs of equal Collatz height.
Relation to the 3x+1 problem: a(n) resolves A398792 level by level, counting the classes that first show this merging at level n+1; the class counted at n = 2 is Garner's pair (8m+4, 8m+5). Like A398792, the sequence is not evidence for or against the Collatz conjecture, since the map (3x-1)/2 gives the same values.

A398794
Number of values 0 <= r < 2^n such that the trajectories of r and r+1 under the 5x+1 map f (A185452), satisfy f^(n)(r) = f^(n)(r+1) and contain the same number of odd terms among the first n iterates.

COMMENTS
The analog of A398792 for the 5x+1 map (A185452). No convergence assumption is involved: merging at the same step index with equal odd count is a finite event decided by the residue class (Terras's parity argument is valid for every map (q*x+1)/2 with q odd), so the count is well defined even though 5x+1 trajectories are believed to diverge.
The density a(n)/2^n at n = 22 is 0.0044, against 0.409 for the Collatz map (A398792) and 0.107 for 7x+1 (A398795). On a step where both members of a pair have the same parity the difference is multiplied by 1/2 (both even) or by q/2 (both odd), so the expected multiplier is (1+q)/4; this equals 1 only for q = 3, and is larger than 1 for q >= 5. The densities observed for q >= 5 are much smaller than for q = 3, but they are nondecreasing in n and they are not ordered by q: q = 7 gives a larger density than q = 5.
Relation to the 3x+1 problem: comparing this count with A398792 and A398795 singles out q = 3 as the only map in the family (q*x+1)/2 for which the difference of a consecutive pair neither grows nor shrinks on average, one precise sense in which the Collatz map is the borderline case of its family.

COMMENTS
The analog of A398792 for the 7x+1 map; see A398794 for why the count is well defined without any convergence assumption. The density a(n)/2^n at n = 22 is 0.107, against 0.409 for the Collatz map (A398792) and 0.0044 for 5x+1 (A398794); it is nondecreasing in n and grows slowly on the computed range.
For maps (q*x+r)/2 with an odd prime p dividing r but not q, the corresponding count is 0 for every n: mod p the map is multiplication by units (2^-1 or 2^-1*q), and merging at equal step and odd counts equalizes the accumulated factors, forcing r == r+1 (mod p), which is impossible. (Tested on (5x+3)/2, (7x+3)/2 and (3x+5)/2: all identically zero.)
Relation to the 3x+1 problem: comparing this count with A398792 and A398794 singles out q = 3 as the only map in the family (q*x+1)/2 for which the difference of a consecutive pair neither grows nor shrinks on average, the expected multiplier being (1+q)/4. The three counts are not ordered by q: q = 7 gives a larger density than q = 5. Like A398792, this is not evidence for or against the Collatz conjecture.
