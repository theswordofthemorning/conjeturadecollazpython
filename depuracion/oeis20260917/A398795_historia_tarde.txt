Number of values 0 <= r < 2^n such that the trajectories of r and r+1 under the map f(x) = x/2 for x even, (7*x+1)/2 for x odd, satisfy f^(n)(r) = f^(n)(r+1) and contain the same number of odd terms among the first n iterates.

COMMENTS
The analog of A398792 for the 7x+1 map; see A398794 for why the count is well defined without any convergence assumption. The density a(n)/2^n at n = 22 is 0.107, against 0.409 for the Collatz map (A398792) and 0.0044 for 5x+1 (A398794); it is nondecreasing in n and grows slowly on the computed range.
For maps (q*x+r)/2 with an odd prime p dividing r but not q, the corresponding count is 0 for every n: mod p the map is multiplication by units (2^-1 or 2^-1*q), and merging at equal step and odd counts equalizes the accumulated factors, forcing r == r+1 (mod p), which is impossible. (Tested on (5x+3)/2, (7x+3)/2 and (3x+5)/2: all identically zero.)
Relation to the 3x+1 problem: comparing this count with A398792 and A398794 singles out q = 3 as the only map in the family (q*x+1)/2 for which the difference of a consecutive pair neither grows nor shrinks on average, the expected multiplier being (1+q)/4. The three counts are not ordered by q: q = 7 gives a larger density than q = 5. Like A398792, this is not evidence for or against the Collatz conjecture.

EXAMPLE
a(4) = 1: the residue r = 8 satisfies f^(4)(8) = f^(4)(9) = 4 with one odd step on each side (8 -> 4 -> 2 -> 1 -> 4 and 9 -> 32 -> 16 -> 8 -> 4).

(Python)
def a(n):    
c = 0    
for r in range(2**n):        
x, y, sx, sy = r, r+1, 0, 0        
for _ in range(n):            
sx += x & 1; sy += y & 1            
x = (7*x+1)//2 if x & 1 else x//2            
y = (7*y+1)//2 if y & 1 else y//2            
if x == y:                
c += sx == sy                
break    
return c
