NAME
Number of residues r mod 2^(n+1) such that r and r+1 have the same image and the same number of odd terms after n+1 iterations of the Collatz map T (A014682), T(x) = x/2 if x is even and (3x+1)/2 if x is odd,  and such that r mod 2^n does not already have this property at level n; a(n) = A398792(n+1) - 2*A398792(n).
COMMENTS
Let f^(n) denote the n-th iteration of the Collatz map.
Nonnegative for all n: by Terras's theorem (1976) the first n parities of a trajectory depend only on the residue mod 2^n, and Tf^(n)(2^n*m + r) = 3^s*m + Tf^(n)(r), where s is the number of odd terms among the first n iterates of r. Taking m = 1 shows that if r is counted in A398792 at level n, then both r and r + 2^n are counted at level n+1, whence A398792(n+1) >= 2*A398792(n).
PROG
(Python) # b(n) via the program in A398792: b = lambda n: a(n+1) - 2*a(n)

NAME
Number of residue classes mod 2^(n+1) of merging consecutive Collatz pairs that are not inherited by doubling from level n.
Number of residues r mod 2^(n+1) such that r and r+1 have the same image and the same number of odd terms after n+1 iterations of the Collatz map T (A014682), T(x) = x/2 if x is even and (3x+1)/2 if x is odd, and such that r mod 2^n does not already have this property at level n; a(n) = A398792(n+1) - 2*A398792(n).
COMMENTS
Nonnegative for all n because A398792(n+1) >= 2*A398792(n) (proved: with m = 1 in Terras's identity, both r and r + 2^n inherit the merging property).
Nonnegative for all n: by Terras's theorem (1976) the first n parities of a trajectory depend only on the residue mod 2^n, and T^n(2^n*m + r) = 3^s*m + T^n(r), where s is the number of odd terms among the first n iterates of r. Taking m = 1 shows that if r is counted in A398792 at level n, then both r and r + 2^n are counted at level n+1, whence A398792(n+1) >= 2*A398792(n).
The ratio a(n+1)/a(n) increases toward 2 on the computed range (1.9469 at n = 35); whether its limit is 2 is equivalent to whether the proved density bound A398792(n)/2^n converges to the full density of consecutive pairs of equal Collatz height.
Relation to the 3x+1 problem: a(n) resolves A398792 level by level, counting the classes that first show this merging at level n+1; the class counted at n = 2 is Garner's pair (8m+4, 8m+5). Like A398792, the sequence is not evidence for or against the Collatz conjecture, since the map (3x-1)/2 gives the same values.

a(n) = A398792(n+1) - 2*A398792(n): number of residue classes mod 2^(n+1) of merging consecutive Collatz pairs that are not inherited by doubling from level n.
DATA
0, 1, 1, 2, 2, 3, 4, 6, 11, 19, 34, 60, 106, 190, 341, 623, 1148, 2124, 3963, 7451, 14072, 26699, 50913, 97379, 186769, 359164, 692079, 1336125, 2583668, 5002992, 9701007, 18831364, 36594031, 71181933, 138581314
OFFSET
1,4
COMMENTS
Nonnegative for all n because A398792(n+1) >= 2*A398792(n) (proved: with m = 1 in Terras's identity, both r and r + 2^n inherit the merging property).
The pair (2^j - 2, 2^j - 1) merges for the first time at step j+2 for every even j >= 2, with merge point at the ternary repunit (3^(j-1)-1)/2, so new classes appear at infinitely many levels.
The ratio a(n+1)/a(n) increases toward 2 on the computed range (1.9469 at n = 35); whether its limit is 2 is equivalent to whether the proved density bound A398792(n)/2^n converges to the full density of consecutive pairs of equal Collatz height.

FORMULA
a(n) = A398792(n+1) - 2*A398792(n).
EXAMPLE
a(2) = 1: the residue class r = 4 mod 8 (Garner's pair (8m+4, 8m+5)) merges at level 3 and is not the doubling of a class merging at level 2.
