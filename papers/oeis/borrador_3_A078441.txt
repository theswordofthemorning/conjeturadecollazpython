%C A078441 Garner (1985) conjectured that there are arbitrarily long runs of consecutive integers with the same height. As recalled by Gao (1993), the runs should have the same height, computed with f as here, and the same number of halving steps (A006666); in that form the conjecture implies that a(n) exists for every n. - _Omar Said_, Sep 27 2026
%C A078441 a(7), a(17), a(25), a(40), a(65), a(98) and a(176) are the starting points of the first seven runs in Table 1 of Gao (1993), which lists the longest run in each range 10^j..10^(j+1); in each of these runs all members also have the same number of halving steps (A006666). The run of 176 integers from a(176) = 722067240 is the longest below 2^30, as found by Wu (1992). - _Omar Said_, Sep 27 2026
