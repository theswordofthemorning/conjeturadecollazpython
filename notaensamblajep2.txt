   (P2-a) LA DOMINACION DEL RELOJ (el lema de racha).
     P(racha >= j | pasado grueso) <= C 2^-j. Estado: la reduccion

     EL ENUNCIADO HONESTO, CON EL WEDGE (post-10a, el sub-lema (b)
     del conteo -- escrito; el (a) ya es teorema:
     unionpalabras.lean). LEMA DE RACHA (condicional al conteo):
     sea rho < 1/2 la razon multi-escala del teorema de conteo
     pendiente y alfa = log2(1/(2 rho)) > 0. Entonces para el mixto
     del paso t y todo j:
       (reg. L2, j + 1 <= alfa t): P(racha_total >= j) <=
         K_imp * sqrt(C2(j+1)) * 2^-(j+1)/2,
         via la union por palabras: cada palabra u de largo j
         define A LO SUMO UNA clase mod 2^(j+1)
         (una_clase_palabra_bit0/bit1) y L2 acota el peso de cada
         clase por Cauchy-Schwarz; K_imp = 1/P(impar|vivo) ~ 2 es
         el pago del condicionamiento al mixto. La condicion
         j + 1 <= alfa t es EL WEDGE: el DP pierde un bit de
         modulo por paso, asi que C2 a escala j+1 solo esta
         controlada uniforme desde t >= (j+1)/alfa (~5,5 j con el
         rho = 0,44 medido).
       (reg. quenched, j + 1 > alfa t): manda el cap determinista
         del FORZADO (P2-b.i): la racha forzada por c_t nunca
         excede 1 + log2|c_t| -- y ese tramo es exactamente el
         prefijo quenched que la ventana T = 20,8 log2|c_i|
         absorbe con margen ~20x (P2-b.iii). Lo realizado por
         encima del forzado en este regimen lo paga el conteo,
         igual que en (P2-b).
     La subcriticidad total del reloj sale de pegar los dos
     regimenes: colas 2^-(j+1)/2 en el bulk (razon 2^(-1/2), la
     que la reescala de ventana absorbe -- c/sqrt(log x)
     invariante) y prefijo acotado quenched. QUE FALTA: solo el
     conteo (rho_ms < 1/2 sobre la orbita) -- este enunciado no
     agrega hipotesis nuevas.

   (P2-b) EL TRAMO INICIAL DETERMINISTA (quenched), ESCRITO
     [REESCRITO POR LA 10a (adv 1, d1; acta M2): la version
     anterior vendia (i) como identidad y (ii) como cota de lo
     REALIZADO -- las dos eran falsas asi leidas; lo exacto es el
     FORZADO]:
     (i) La cota del FORZADO, exacta: para c impar, la racha
         FORZADA PARA TODA PALABRA tras bit 0 es v2((3c+1)/2) --
         la palabra 0...0 corta exactamente ahi -- y |3c+1| <=
         4|c|, asi que
           racha_forzada <= v2(3c+1) - 1 <= 1 + log2|c|
         (v2(n) <= log2|n|: el 2-adico no supera el tamano).
         Identico para bit 1 con |c - 3^(k-1)|. LO QUE NO ES: una
         identidad de lo realizado -- la recarga puede caer DENTRO

         teorema de conteo, no esta cota.
     (ii) EL PRESUPUESTO DE BITS (esquema; la moneda corregida por
         la 10a): "racha >= j" consume j+1 bits bajos de c (la
         clase mod 2^(j+1), lecturaracha) y la moneda correcta es
         DENSIDAD DE CLASE, no magnitud: exigir un perfil de rachas

         2^(>= W) -- probabilidad 2^-W bajo la medida de clases. El
         doble conteo es IMPOSIBLE, ya no como esquema sino
         verificado por dos vias (10a, adv 1): la biyeccion
