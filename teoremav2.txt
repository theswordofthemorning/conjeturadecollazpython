=====================================================================
EL ENUNCIADO (autonomo, cero Collatz)
=====================================================================

Bits justos b_t (dado el pasado); reloj exogeno m_t (mixto con prob
1/2, o rachas geometricas -- ambas variantes valen); paseo k desde 2
que en pasos mixtos baja con b = 1 y sube con b = 0, absorbido en
k = 1 (tiempo tau); perpetuidad u_0 = x, y en TODO paso
u <- u/2 (b = 0) o u <- (3u - 1)/2 (b = 1).

  TEOREMA V2 (objetivo). Existen constantes K y c > 0 (universales,
  independientes de x) con

      phi_V2(x) := P( |u_tau| <= K )  >=  c / sqrt(ln x).

Con esto, la reduccion del programa cierra por su lado autonomo:
Levy solo pide Sigma_i phi(|c_i|) = infinito con arranques planos
(beta = 0 medido), y un piso 1/sqrt(log) lo da de sobra; Liebres
acepta CUALQUIER ventana finita, asi que K universal basta (ver la
pieza 3: la universalidad de K es el punto tecnico de verdad).

PIEZA 1 (clasica): EL PASEO SE ABSORBE EN LA VENTANA TEMPORAL BUENA.
  Sea T = C1 * ln x (C1 a elegir en la pieza 2). Entonces

      P( tau en [T, 2T] )  >=  c1 / sqrt(T).

  Es primer-pasaje de un paseo justo perezoso desde altura 1 sobre
  la barrera: P(sobrevivir T) ~ c/sqrt(T) (reflexion/balota para el
  paseo embebido + concentracion del reloj: mixtos ~ T/2 con
  fluctuacion sqrt(T)), y absorberse en la ventana siguiente cuesta
  un factor constante. Con reloj de rachas geometricas: la
  concentracion del reloj es Chernoff estandar. TODO CLASICO.

PIEZA 2 (elemental -- ni CLT hace falta): LA CONTRACCION CONDICIONADA
  SUPERA ln x POR CHEBYSHEV.
  Condicionado al camino del paseo (que fija los bits de los pasos
  mixtos), los pasos compartidos llevan bits LIBRES y justos. El
  log-multiplicador total al tiempo tau es

      log prod_tau = (forzado por el camino) + (libre)

  con: forzado = -s ln2 + (s+1) ln(3/2) <= ln(3/2) (el balance
  s subidas / s+1 bajadas: QUELTEHUES pieza (2), aqui exacta POR
  CONSTRUCCION); libre = paseo de L_c ~ tau/2 pasos, media
  -0,1438 L_c, desviacion 0,549 sqrt(L_c).
  Con tau >= T = C1 ln x y C1 = 30: media libre <= -2 ln x para
  todo x grande, y desviacion O(sqrt(ln x)) << ln x. Chebyshev:

      P( log prod_tau <= -ln x  |  camino con tau >= T )  >=  3/4.

  O sea: condicionado a durar, la parte multiplicativa del arranque
  MUERE con probabilidad 3/4. Sin CLT, sin grandes desviaciones.
  [VERIFICADO por MC el mismo dia (sonda de scratchpad, 2000 casos
  condicionados por punto): P(contraccion > ln x | tau >= T) =
  0,999-1,000 para x = 2e3 y 2e6, con C1 = 30 Y TAMBIEN con
  C1 = 15 -- el margen real es mucho mayor que el 3/4 de Chebyshev;
  las constantes del plan son holgadas.]

PIEZA 3 (LA TECNICA, molde AGKV): LA PERPETUIDAD DE OFFSETS TIENE
  MEDIANA UNIVERSAL BAJO EL PASEO CONDICIONADO.
  u_tau = prod_tau * x + W_tau, con W_tau = Sigma_j delta_j *
  (producto de j+1 a tau), |delta_j| <= 1/2. Falta:

      (L3)  existe M universal con
            P( |W_tau| <= M  |  camino del paseo, tau en [T, 2T] )
            >= 1/2   UNIFORME en x y en el camino tipico.

  DONDE MUERDE: en los tramos de descenso forzado el multiplicador
  es 3/2 deterministico (E[m^theta] > 1 por paso ahi): la dominacion
  ingenua de Moscas NO cierra paso a paso. Lo que salva es el
  BALANCE del camino (cada bajada tiene su subida, salvo una): el
  producto de cola desde j es (3/4)^(s_j) * (3/2) * (libre_j), y el
  theta-momento de cada termino se acota con el balance mas la
  contraccion media de los libres. ESTE es exactamente el objeto
  theta de AGKV 2005 (la esperanza de la funcional multiplicativa
  bajo el paseo condicionado a positivo, construida con el
  h-transform de Bertoin-Doney); la version Markov-dependiente
  (Grama-Lauvergnat-Le Page) cubre el reloj de rachas.
  LA SUTILEZA QUE ESTE PLAN DEJA ESCRITA (cazada al armarlo): si en
  vez de (L3) se usa Markov sobre un momento que crece con T, la
  ventana K saldria poly(ln x) -- y una ventana que CRECE con x NO
  sirve para Liebres. La universalidad de M es el contenido real de
  la pieza; no hay atajo por momentos crudos.

COMPOSICION. P(|u_tau| <= M + 1) >= P(pieza 1) * (3/4 - 1/2 ...) --
las piezas 2 y 3 son condicionales al mismo camino: interseccion
>= 1/4 condicional >= (c1/sqrt(T)) * 1/4 = c / sqrt(ln x) con
K = M + 1. QED (modulo L3 y la escritura fina de 1 y 2).

LEMA 1 (el paseo dura). Existe c1 > 0 universal y T0 con: para todo
T >= T0,
    P( tau >= T )  >=  c1 / sqrt(T).
Demostracion. El paseo embebido (solo pasos mixtos) es +-1 justo
desde altura 1 sobre la barrera; P(sobrevive m movimientos) >=
c/sqrt(m) es la balota clasica. En T pasos hay a lo sumo T
movimientos, luego {embebido sobrevive T movimientos} implica
{tau >= T} (la pereza solo alarga). QED. (Notese que NO hace falta
la cota superior de tau en las piezas 1-2.)

LEMA 2 (los compartidos abundan, sin tocar el condicionamiento).
    P( L_c(T) < 0,4 T )  <=  e^(-T/50)      (Chernoff, Binomial(T,1/2)).
Por tanto
    P( tau >= T, L_c(T) >= 0,4 T )  >=  c1/sqrt(T) - e^(-T/50)
                                    >=  (c1/2)/sqrt(T)   para T grande.
(El truco: NO se condiciona el reloj al paseo -- se restan eventos.
La correlacion reloj-supervivencia, que ademas va a favor, no hace
falta ni mencionarla.)

LEMA 3 (pieza 2: la contraccion condicionada). Sea G la sigma-algebra
del reloj y de los bits mixtos (el "camino"). En el evento
{tau >= T, L_c(T) >= 0,4 T} vale, para todo x >= x0 (universal):
    P( S(tau) <= -log x  |  G )  >=  3/4.
Demostracion. Dado G, S(tau) = F + S_libre con:
  (a) F = suma sobre mixtos = -s log 2 + (s+1) log(3/2) =
      log(3/2) - s log(4/3) <= log(3/2)  (el balance: d = s + 1
      bajadas por construccion de la absorcion desde 2 hasta 1).
  (b) S_libre = suma de L_c >= 0,4 T = 12 log x variables iid con
      media mu y varianza sigma^2 (los bits compartidos son libres
      dado G: el reloj es independiente y los bits mixtos no
      constrinen a los compartidos).
  E[F + S_libre | G] <= log(3/2) - 0,14384 * 12 log x =
      log(3/2) - 1,726 log x.
  El objetivo -log x queda a distancia >= 0,726 log x - log(3/2) de
  la media, y la desviacion tipica es sigma sqrt(L_c) <= 0,549
  sqrt(L_c); Chebyshev con dos desviaciones exige
      0,726 log x - 0,405 >= 2 * 0,549 * sqrt(L_c).

  engorda la varianza si tau >> T). Se parte en dos: si L_c <= C3

  crece LINEAL en L_c (0,14384 L_c) y la desviacion como sqrt --
  para L_c >= 12 log x, media - 2sd <= -0,14384 L_c +
  1,0986 sqrt(L_c) <= -log x - 1 en cuanto L_c >= 12 log x y
  log x >= 60 (resolver la cuadratica en sqrt(L_c): el minimo del
  margen se da en el extremo inferior L_c = 12 log x, donde
  0,726 log x - 0,405 - 1,0986 sqrt(12 log x) >= 0, cuya raiz

  log x >= 29, x0 = e^29 ~ 4e12, y Chebyshev con dos desviaciones

    A~ = 1/2]  -- el h-transform del paseo justo con h(k) = k - 1.
P~_r = A~_1 ... A~_r;  W~ = Sigma_r d~_r P~_{r-1}, d~_r = -(1/2)

LEMA (ii) [la serie revertida converge -- el analogo del Lemma 2.7
de AGKV]. Bajo P~+, existe c > 0 con P~_r <= e^{-c r} eventualmente

DEMOSTRACION.
(1) La descomposicion del log-producto. Sean a_r / d_r las subidas/
    bajadas mixtas hasta r, L_c(r) los compartidos, S_f(r) la suma
    de log A~ de los compartidos. Como k~_r = 2 + a_r - d_r >= 2,
      log P~_r = log(3/2) a_r - log 2 d_r + S_f(r) + log(3/2)
               = log(3/2)(k~_r - 2) - log(4/3) d_r + S_f(r)
                 + log(3/2)
      <= 0,406 (k~_r - 2) + S_f(r) + 0,406        [d_r >= 0].
(2) Los compartidos abundan: L_c(r) ~ Binomial(r-1, 1/2) (el reloj
    es iid por construccion), Chernoff: P(L_c(r) < 0,4 r) <=
    e^{-r/50}; Borel-Cantelli: L_c(r) >= 0,4 r eventualmente c.s.
(3) La parte libre contrae: dados los compartidos, sus log A~ son
    iid con media mu = -(1/2) log(4/3) = -0,1438 y rango log 3.
    Hoeffding: P( S_f(r) > -0,07 L_c(r) ) <= exp(-2 (0,0738)^2
    L_c(r) / (log 3)^2 ) <= e^{-0,009 L_c(r)}. Con (2) y
    Borel-Cantelli: S_f(r) <= -0,07 * 0,4 r = -0,028 r
    eventualmente c.s.
(4) El paseo condicionado no trepa mas que sqrt: para todo
    delta > 0,  k~_r <= r^{1/2 + delta} eventualmente c.s.
    Prueba: h(k~_{n ^ tau_1}) es martingala del paseo original, y
    por parada opcional el h-transform satisface, para m >= 3,
      P~+( tau_m <= R ) = (m - 1) P_2( tau_m <= R, tau_m < tau_1 )
    donde P_2 es el paseo perezoso justo original desde 2 y tau_m
    su primer paso por m. El maximo de un paseo justo de
    incrementos acotados por 1 cumple (martingala exponencial +
    desigualdad maximal de Doob)
      P_2( tau_m <= R ) <= exp( -(m - 2)^2 / (2R) ).
    Con m = R^{1/2+delta}: P~+( max_{r <= R} k~_r >= R^{1/2+delta} )
    <= R^{1/2+delta} exp( -R^{2 delta}/2 + o(1) ), sumable en R
    (basta por potencias R = 2^j); Borel-Cantelli da (4).
    [Capa 1, 11-08 (2): la identidad de parada opcional verificada
    por MC en regimen que muerde -- (m, R) = (6,12), (9,20),
    (9,40), (12,40), probabilidades 0,19-0,60, cocientes
    P~+/(m-1)P_2 = 0,997-1,009, todo dentro del ruido de N=6e5.]
(5) Composicion: log P~_r <= 0,406 r^{1/2+delta} - 0,028 r + O(1)
